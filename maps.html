지도를 만드는 방법

1
찾기
질문을 검색어 여러 개로 나눠 공공데이터포털·서울 열린데이터광장·KOSIS·한국은행 ECOS 같은 곳에서 후보 데이터셋을 찾습니다.
2
메타데이터 읽기
데이터셋 화면과 API 명세에서 제공기관·갱신 주기·기간·칸 이름·이용 조건을 읽습니다. 직접 본 것과 추정한 것을 나눠 적습니다.
3
잇고 판단하기
칸 이름과 코드 체계로 서로 이을 수 있는지, 기간이 겹치는지, 앱에 보여줘도 되는지를 정리합니다.

지금 있는 두 지도는 사람이 조사한 수동판입니다. 지도 페이지는 데이터를 받아 오지 않고 메타데이터만 보여줍니다. 순매수 그래프는 ECOS에서 한 번 받아 둔 값을 싣습니다. 이용 조건 해석은 각 사이트의 약관 문구를 옮긴 것이며 법률 자문이 아닙니다.
