AI 기술의 흐름을 재는 공개 데이터

새 기술은 대개 논문에서 시작해 오픈소스 코드가 되고, 개발자가 내려받기 시작하고, 모델로 퍼지고, 마지막에 큰돈이 들어갑니다. 그 다섯 단계를 재는 공개 데이터를 한 장에 놓고 — 무엇으로 서로 잇는지, 어디까지 공개해도 되는지를 함께 적었습니다. 채운 점은 지금 신호에 쓰는 데이터, 빈 점은 다음 후보입니다.기술은 논문 → 오픈소스 → 개발자 채택 → 모델 → 자본 순으로 퍼집니다. 단계마다 쓸 수 있는 공개 데이터와, 어디까지 공개해도 되는지를 정리했습니다.

이용 조건 2026-10-24 확인 · 약관 문구를 옮긴 것이며 법률 자문이 아닙니다

무엇으로 잇나

서로 다른 데이터를 같은 기술로 묶으려면 공통 열쇠가 필요합니다.

날짜 — 일 · 주 · 월 · 분기패키지 이름GitHub 저장소모델 · 만든 곳회사 (SEC CIK)키워드
  • 패키지 ↔ 저장소 — npm·PyPI 패키지 정보에 GitHub 저장소 주소가 적혀 있어, 다운로드와 스타·릴리스를 같은 프로젝트로 묶을 수 있습니다.
  • 만든 곳 ↔ 회사 — Hugging Face의 만든 곳(meta-llama, google 등)과 SDK 패키지(openai, anthropic)는 회사 단위로 묶이고, 상장사는 SEC CIK로 설비투자·매출과 이어집니다.
  • 키워드 ↔ 패키지 — 논문 속 말(예: model context protocol)과 그 이름의 패키지(mcp)를 나란히 놓으면, 연구에서 채택까지 걸린 시간을 볼 수 있습니다.
  • 날짜 — 다운로드는 일, 논문은 월, 설비투자는 분기입니다. 주 단위로 모으되, 합계(다운로드)인지 기말 값(점유율)인지 나눠서 잇습니다.

이 지도가 말하지 않는 것

  • “조건이 적혀 있지 않음”은 허락이 아닙니다. 약관이 집계 숫자의 재게시를 따로 다루지 않는다는 뜻일 뿐입니다. 그래서 숫자는 집계만 싣고 원자료를 다시 나눠 주지 않으며, 출처를 밝힙니다.
  • 후보는 아직 받아 보지 않은 데이터입니다. 신호에 넣기 전에 실제 응답과 검산을 다시 확인합니다.
  • 약관은 바뀝니다. 위 문구는 2026-10-24에 읽은 것입니다.
