이 숫자로 말할 수 없는 것

  • 다운로드는 사용자 수가 아닙니다. 한 사람이 여러 번, 자동 빌드가 수천 번 내려받습니다. 그래서 크기 비교보다 같은 소스 안에서의 변화와 비율을 봅니다.
  • 대조군도 움직입니다. 개학·연말처럼 소스 전체가 함께 오르내리는 때가 있습니다. "대조군 대비"는 그 몫을 뺀 값이지만, 대조군 다섯 개가 소스 전체를 완벽히 대표하지는 않습니다.
  • 집계가 바뀌거나 늦는 때가 있습니다. PyPI는 2026년 8월 말 한꺼번에 반으로 줄었고, npm은 0으로 적힌 날이 있습니다. 둘 다 아래 검산에 그대로 적고, 계산은 그 몫을 피하도록 했습니다 — 그래도 완전히 피했다고 장담하지 않습니다.
  • 논문 비율은 초록에 그 말이 있는지만 봅니다. 말이 유행하는 것과 기술이 쓰이는 것은 다릅니다.
  • 설비투자는 AI만의 돈이 아닙니다. 물류 창고·사무실도 같은 항목에 들어갑니다.
  • 예측하지 않습니다. 지난 숫자가 어떻게 움직였는지까지만 씁니다. 특정 회사나 종목의 투자 판단을 권하지 않습니다.

출처와 이용 조건 (2026-10-24 약관 확인)

  • npm 다운로드 수 공개 API(api.npmjs.org/downloads). 공개 API로 제공되며, 다운로드 수를 다른 곳에 싣는 데 대한 조건은 약관에 따로 적혀 있지 않습니다. npm과 관계가 있거나 승인받은 것처럼 보이지 않게 적습니다.
  • PyPI pypistats.org API — 원자료는 PyPI의 BigQuery 공개 데이터셋이며 CC BY 4.0입니다(docs.pypi.org/api/bigquery). pypistats는 결과를 캐시해 하루 한 번만 받으라고 안내합니다.
  • arXiv API — 메타데이터는 CC0 1.0. 요청은 3초에 한 번 이하. 이 페이지는 arXiv가 승인하거나 지원하는 것이 아닙니다.
  • Hugging Face Hub API — 모델 목록의 다운로드 수(지난 30일, Hub 기준). 다운로드 수를 싣는 데 대한 조건은 약관에 따로 적혀 있지 않습니다.
  • SEC EDGAR XBRL companyfacts — 미국 정부 공개 자료. 현금흐름 항목은 연초부터 누적으로 공시돼 분기 값은 차이로 구합니다.
